# Security

Report vulnerabilities through this repository's **Security → Report a vulnerability**
form. Please include the affected revision and steps to reproduce, and omit
real documents, credentials and tokens. Please do not open a public issue for
an unpatched security issue.

Deploy the workspace on loopback or behind a trusted HTTPS proxy. Keep account
configuration, model and database credentials, and session files private. The
workspace account is shared; use a separate deployment for a different trust boundary.
