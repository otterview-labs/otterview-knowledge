# Source provenance

OtterView Knowledge is the standalone edition of the knowledge workspace.
The original runtime was developed as JetLinks Knowledge Runtime. An earlier
snapshot of its backend was published in DocuGen; see the
[DocuGen source provenance](https://github.com/otterview-labs/DocuGen/blob/main/docs/PROVENANCE.md)
for the baseline revision and files.

This edition includes changes to the standalone account and UI, deferred
full-document summaries and document relationships, and OCR-assisted ingestion.
The release snapshot also changes the product branding, deployment defaults,
and documentation. The initial commit contains the source snapshot; it does
not import the original repository's history or runtime state.
